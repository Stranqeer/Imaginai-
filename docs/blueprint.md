# **App Name**: ImaginAI

## Core Features:

- Image Generation: Generate images from user-provided text prompts, using an AI tool such as DALL-E or Stable Diffusion. The app passes the user prompt directly to the tool.
- Image Display: Display generated images with a clean, responsive design.
- Prompt Input: Simple input field for users to enter their image prompts.
- Clear Input/Image: Option to clear the current image and prompt
- Image Downloading: Option to download images generated in different formats

## Style Guidelines:

- Primary color: Saturated blue (#4285F4) to represent technology and creativity.
- Background color: Light gray (#F5F5F5) for a clean, neutral backdrop.
- Accent color: Teal (#00BCD4) for interactive elements and highlights, providing a modern, eye-catching feel.
- Body and headline font: 'Inter', a sans-serif font for a clean and modern user interface.
- Simple, outline-style icons to maintain a clean and modern aesthetic.
- Clean, grid-based layout to showcase images effectively.
- Subtle loading animations to enhance user experience during image generation.
